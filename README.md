### Project 3. Microsoft Stock Time Series

---

A time series analysis project in R focused on Microsoft stock data and forecasting. The project includes data cleaning, time series decomposition, stationarity testing, data transformations, ARIMA model selection, and residual diagnostics. Holt-Winters and ETS forecasting models are evaluated using RMSE, MAE, MAPE, and Theil's U to compare forecasting performance.
